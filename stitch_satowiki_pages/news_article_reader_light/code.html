The Activation of Taproot: A Retrospective

Andreas M.

Protocol Researcher • Nov 14, 2023

It has been several years since block 709,632, the moment the Taproot upgrade officially activated on the main network. This represented the most significant protocol upgrade since Segregated Witness (SegWit) in 2017.

The journey to Taproot was marked by extensive technical review, community consensus-building, and a novel activation mechanism known as Speedy Trial. This retrospective examines the technical underpinnings, the activation process, and the long-term implications for script complexity and privacy.

The Technical Trifecta

Taproot is not a single feature, but a bundle of three distinct yet interconnected technical proposals, defined in BIP-340, BIP-341, and BIP-342.

  • key

    Schnorr Signatures (BIP-340)

    Replaces ECDSA, offering linearity. This allows for signature aggregation, where multiple signatures in a complex transaction can be combined into a single signature, saving space and improving privacy.

  • account_tree

    Taproot (BIP-341)

    Integrates Merkelized Alternative Script Trees (MAST) with Schnorr. It allows smart contracts to look like standard pay-to-public-key-hash (P2PKH) transactions on-chain, revealing only the executed conditions.

  • code

    Tapscript (BIP-342)

    Updates the scripting language to support Schnorr and Taproot, ensuring future upgradability by removing certain op-code limits and redefining others.

The combination of these elements dramatically shifted the paradigm of complex transactions. Prior to Taproot, multi-signature setups or time-locked contracts exposed their entire logic upon execution. This was inefficient in terms of block space and detrimental to privacy.

Activation: The Speedy Trial

Learning from the contentious block size wars of 2017, the community opted for a different approach to activation. The chosen path, "Speedy Trial," provided a three-month window for miners to signal their readiness. If 90% of blocks in a difficulty adjustment period (2016 blocks) signaled support, the upgrade would lock in.

"Speedy Trial decoupled the technical readiness from the political debate. It gave developers a clear signal without enforcing a hard mandate on users prematurely."

The threshold was met surprisingly quickly, locking in during June 2021, and activating in November. This smooth process demonstrated a maturation in the network's governance and upgrade mechanisms.
