# Code of Conduct

SatoWiki follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

We want this project to be a place where anyone can learn and contribute, whatever their background or level of experience.

- Be respectful and patient, especially with beginners. Explaining Bitcoin to newcomers is the reason this project exists.
- Argue about facts and sources, not about people.
- Accept correction gracefully, and give it kindly.
- No harassment, insults, personal attacks or discriminatory language.
- No promotion of coins, tokens, products or services, and no investment advice.

## Scope

This applies to every project space: issues, pull requests, discussions and review comments.

## Reporting

If you see or experience behavior that breaks these rules, contact the maintainer privately through their GitHub profile, [@Dado-hash](https://github.com/Dado-hash). Reports are kept confidential.

Maintainers may remove, edit or reject comments, commits, issues and other contributions that break this Code of Conduct, and may block repeat offenders from the project.
